# TILT rules

## Movement

A swipe changes gravity to up, right, down, or left. Every live block moves at the same time and slides until it reaches the board edge, a wall, or another block.

## Blocks and goals

A level contains one or two blocks. Each block has one matching goal, identified by the same colour and symbol. A block is collected only when it stops on its own goal; crossing a goal or stopping on the other colour's goal does nothing.

## Clear condition

A level clears after every block has been collected by its matching goal. Blocks touching each other is not a clear condition. Contact only matters because one block can stop another.

There are no SELECT, MATCH, or FORM objectives in the current campaign.
